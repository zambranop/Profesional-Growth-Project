# **90-Day Execution Plan**

| Week | Focus | Key Actions |
| :---- | :---- | :---- |
| Weeks 1-2 | Foundation | Update LinkedIn headline \+ About. Build Tier 1 company list (20 companies). Map existing US/Canada contacts. Draft your 3 STAR interview stories. |
| Weeks 3-4 | Activation | Send warm network messages to all US/Canada contacts. Begin cold outreach to 3 Tier 1 companies. Post 2x on LinkedIn. Start commenting on target company decision-maker posts. |
| Weeks 5-8 | Pipeline Building | Maintain weekly outbound targets. Apply to 5-8 targeted roles per week. Follow up on all warm conversations. Track every application and conversation in a simple log. |
| Weeks 9-12 | Conversion | Review what is working (which companies are responding, which message templates convert). Double down on the highest-signal channels. Request feedback from any process you exit without an offer. |
